# UI documentation map

**Status:** Existing view map plus the six-area UI refresh. Every view/panel gets a short
explanation and a documentation deep-link; this file is the canonical map used to build and
audit those links. See [UI design audit and plan](UI-DESIGN-IMPLEMENTATION-PLAN.md).

## Link contract

Each panel should use one short sentence and one link:

```html
<p class="section-help"><span>What this does in one sentence.</span>
  <a class="doc-link" href="#docs?doc=docs/WEB-UI.md&amp;anchor=pages">Read more</a></p>
```

The docs route is `#docs?doc=<path>&anchor=<slug>`. Heading slugs are generated by
`strength_coach/web/markdown.py`; duplicate headings get `-2`, `-3`.

Every linked document should end with:

```markdown
## Related

- **Evidence:** [REFERENCES.md](REFERENCES.md)
- **Decisions:** [DECISIONS.md](DECISIONS.md)
- **Open questions:** [OPEN-QUESTIONS.md](OPEN-QUESTIONS.md)
- **Roadmap:** [ROADMAP.md](../ROADMAP.md)
```

Operational pages (Settings, Docs) may replace “Evidence” with the relevant implementation
or parity document. The Terminal view was removed on 2026-10-28 (`DEC-WEB-02`).

## Principal navigation areas

The sidebar groups existing routes into six task areas. These groups organize and expose the
current destinations; they do not duplicate their forms or imply new data contracts.

| Area | Destinations |
|---|---|
| **Today** | Today action hub |
| **Training** | Workflow, History, Exercises |
| **Progress** | Overview, Performance, Outcomes |
| **Health & Longevity** | Longevity overview, Cardio, Measures, Readiness settings |
| **Programme Intelligence** | Prescribe diagnostics, Programme forecast, Review |
| **Administration** | Athlete, Import, Settings, Logs, Docs |

## Panel-specific notes
