# REFERENCES — the scientific sources behind the rules

A consolidated bibliography of the papers retrieved while building the evidence notes. Every
entry was fetched during this work (Europe PMC / publisher records) and has a DOI. Where a
paper informed a decision, the "used for" column says which.

Dates are the publication dates in the retrieved record (some are 2026 issues). This is a
reference list, not an endorsement: study quality varies, and the evidence notes say where a
conclusion is weaker than it looks.

## Not included

Search results that were unrelated to this project (e.g. cerebral autoregulation, blood-flow
restriction, ACL rehabilitation, load carriage) were not retained. A reference here is not a
claim that the study is definitive; the evidence notes state the limitations.
