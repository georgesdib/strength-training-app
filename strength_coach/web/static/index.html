Continuity calibration

loading…

Return-to-training retention from actual gaps. Each band uses a calibrated factor only when it has enough returns and a tight bootstrap interval; otherwise the fixed −5%/−10% rule remains. This is not the e1RM age decay.

Weekly volume

advisory hard-set ledger

Working sets per movement pattern over the last four weeks, compared with broad config targets. It reports drift; it does not change the prescription.

Strength fatigue model

shadow; no load effect

Per-lift and overall fitness/fatigue fit from your own e1RM observations; approximate 95% intervals. It refuses sparse or ill-conditioned fits; nothing here changes the prescription above.

Exercise selection

preview; applies only when ticked above

Ranks the configured variants for each slot using readiness, recent stress, rotation and preference. Tick Apply selection above to let the chosen candidates replace the slot exercise; the load is then re-solved from the selected lift's own history. The model option may only choose from that ranked list; Python falls back deterministically.

Retrospective validation

walk-forward; no prescription change

Replays past cutoffs using only earlier data. It checks continuity and the strength fatigue model against simple baselines; volume is descriptive only and selection has no counterfactual. Not prospective validation.

Import training and readiness

both CSVs

Upload the two exports. The browser sends the file text to this local process; the bytes are parsed, hashed and stored as raw rows in data/coach.db. Nothing is saved as a file in the repository.

Re-importing the same files is idempotent: existing raw rows and clean sets are reported, not duplicated.

After the import

calibration is not an import step

The short answer: do not run a calibration because you imported. Import adds sessions; calibration compares the engine's rubric with your marks. With no marks, calibrate says no marks yet.

  1. Check the report above. New raw rows/sessions are the history that was added; overlapping means it was already loaded. A high quarantined count means dates or exercise names need attention.
  2. Review recent sessions. Open Review and mark the sessions you remember (or run strength-coach review --pending). Those marks are the calibration labels; only high-confidence marks count.
  3. Calibrate later. After the review — weekly, or after a block — run Run rubric calibration on the Review page (or strength-coach calibrate). Re-importing does not invalidate marks, and importing does not require a re-run on its own.

Review the recent sessions, not the distant past: the pending review stops at your last reviewed session. Rubric calibration and readiness calibration are different reports; neither changes weights automatically.
